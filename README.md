# Smart Campus Lost & Found Portal 🎓

## 📌 About the Project
Smart Campus Lost & Found Portal is a beginner-friendly web project developed using HTML5. It is designed to help students report lost belongings and view items found around their college campus.

The project demonstrates how HTML5 can be used to structure a simple campus information portal with item listings and a report submission form.

## 🎯 Objectives
- Build a structured webpage using HTML5.
- Practice semantic HTML elements.
- Create accessible forms for reporting lost and found items.
- Display item information using HTML tables and lists.
- Understand basic website navigation.

## 🛠️ Technologies Used
- HTML5

## ✨ Features
- Campus portal introduction
- Lost items table
- Found items list
- Lost and found reporting form
- Form validation using HTML attributes
- Navigation links to different sections
- Semantic page structure

## 📚 HTML5 Concepts Covered
- HTML document structure
- Semantic elements: `header`, `nav`, `main`, `section`, and `footer`
- Tables: `table`, `thead`, `tbody`, `tr`, and `th`
- Forms: `form`, `input`, `select`, `textarea`, and `button`
- Form attributes: `required`, `type`, `name`, and `id`
- Labels and accessible form controls
- Ordered and unordered lists
- Anchor links and section IDs
- Meta tags and responsive viewport configuration

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the different sections and try the report form.

## ⚠️ Project Limitations
This is a static HTML5 prototype. Form submissions are not stored in a database, and the portal does not yet provide real-time updates.

- Add user authentication and secure report management.
